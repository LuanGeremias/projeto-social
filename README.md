📱 Projeto Social – Interface com Redes Sociais

Este repositório apresenta um projeto de interface interativa que simula um dispositivo móvel, onde é possível acessar diferentes redes sociais ao clicar nos ícones exibidos na tela.

O projeto foi desenvolvido com HTML5 e CSS3, utilizando iframe para carregar dinamicamente o conteúdo das páginas dentro da estrutura principal, proporcionando uma navegação prática e integrada sem a necessidade de redirecionamentos.

Além disso, foram aplicados conceitos de posicionamento, organização de layout e estilização, com foco em criar uma experiência visual semelhante à de um smartphone.

Este projeto reforça o uso de recursos mais avançados no front-end e demonstra a aplicação prática de navegação dinâmica em páginas web.

🚀 Tecnologias utilizadas: HTML5, CSS3 e iframe
📚 Foco: Interatividade, navegação dinâmica e layout
💡 Objetivo: Explorar novas formas de exibição de conteúdo e melhorar a experiência do usuário
